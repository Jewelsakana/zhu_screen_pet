# PNG 动作序列

将透明背景 PNG 按以下目录和名称放置；文件按名称排序播放：

```text
animations/
├── idle/frame_00.png       # 一次眨眼序列，约每 3.5–6.5 秒触发
├── thinking/frame_00.png   # 思考时循环播放
├── speaking/frame_00.png   # 回复时循环播放
└── level_up/frame_00.png   # 升级后的 10 秒内循环播放
```

建议同一组图片使用相同画布尺寸、透明背景，并保持角色锚点一致。任一目录不存在、
没有 PNG 或图片无法读取时，该状态会自动回退到 `pet_avatar.png`，不会阻止程序启动。

当前仓库只提供播放框架和资源约定，四组正式动作素材尚待补充。
